# TCE — сайт на чистом PHP

Многостраничный адаптивный сайт строительно-инженерной компании. Без фреймворков,
без Composer, без базы данных — весь контент лежит в одном PHP-массиве.

## Установка

1. Распакуйте папку в `D:\tce.az\tce-php`.
2. Поднимите локальный сервер:
   - **OpenServer / Laragon / XAMPP** — укажите корнем документа папку `tce-php`, включите `mod_rewrite`.
   - Либо через встроенный сервер PHP:
     ```
     cd D:\tce.az\tce-php
     php -S localhost:8000 router.php
     ```
3. Откройте `http://localhost:8000`.

Требуется PHP 8.0 или новее (используется `str_starts_with`).

### Если сайт лежит в подпапке

Например по адресу `site.az/tce-php/`:

- в `config/site.php` укажите `'base_url' => '/tce-php'`;
- в `.htaccess` раскомментируйте `RewriteBase /tce-php/`.

## Перенос контента со старого сайта на WordPress

Сайт собран на Elementor, а у него текст лежит **не** в `post_content`, а в мета-поле
`_elementor_data` в виде JSON. Обычные конвертеры этого не видят и выдают пустые
страницы — импортёр в комплекте разбирает оба места.

**Шаг 1. Выгрузите контент.**
В админке: `Инструменты → Экспорт → Всё содержимое → Скачать файл экспорта`.
Получите XML (формат WXR). Положите его рядом с папкой сайта.

**Шаг 2. Запустите импортёр.**

```
cd D:\tce.az\tce-php
php tools/import-wp.php export.xml --media
```

Флаги:
- `--media` — скачать все картинки в `assets/img/imported/`;
- `--limit=50` — ограничить число картинок (для пробного запуска).

**Шаг 3. Заберите результат.**

| Файл | Что внутри |
|---|---|
| `storage/import-report.txt` | весь текст в читаемом виде — открывайте и копируйте |
| `config/content.imported.php` | те же данные структурой, для переноса в `config/site.php` |
| `storage/media-map.json` | какой старый URL стал каким локальным путём |
| `assets/img/imported/` | скачанные картинки |

Импортёр **ничего не перезаписывает** — `config/site.php` остаётся нетронутым.
Перенесите нужные тексты и пути к фото в него вручную: так вы заодно почистите
мусор, который накопился в Elementor за время работы сайта.

Требуется расширение `php-xml` (в OpenServer, Laragon и XAMPP включено по умолчанию).

**Если экспорт не открывается** — файл может быть большим. Экспортируйте по частям:
отдельно страницы, отдельно записи, отдельно медиафайлы.

**Картинки можно забрать и напрямую** — скачайте по FTP папку `/wp-content/uploads/`
и положите файлы в `assets/img/`. Это надёжнее, если хостинг блокирует
скачивание скриптом.

## Как менять контент

Почти всё редактируется в **`config/site.php`** — шаблоны трогать не нужно:

- телефон, почта, адрес, часы работы — блок `contacts`;
- пункты меню — `nav`;
- услуги — `services` (каждая с описанием и списком работ);
- проекты — `projects` (slug формирует адрес `/layihe/slug`);
- партнёры, цифры, преимущества, этапы работ — соответствующие блоки.

## Изображения

Положите файлы по этим путям (имена указаны в `config/site.php`):

```
assets/img/projects/villa.jpg
assets/img/projects/glass-house.jpg
assets/img/projects/xs-apartment.jpg
assets/img/projects/pool-house.jpg
assets/img/partners/p01.png … p08.png
```

Пока файла нет, автоматически подставляется заглушка `assets/img/placeholder.svg`
— сайт не ломается. Рекомендуемый размер обложек: 1600×1200 px, формат WebP или JPEG.

## Форма обратной связи

По умолчанию письма **не отправляются**, заявки пишутся в `storage/messages.log`.
Чтобы включить почту, в `config/site.php`:

```php
'mail' => [
    'to'      => 'info@tce.az',
    'enabled' => true,
],
```

Функция `mail()` на локальном компьютере обычно не работает. На боевом хостинге
надёжнее подключить SMTP (PHPMailer) — замените вызов `mail()` в
`includes/functions.php`, строка ~135.

Уже реализовано: CSRF-токен, ловушка для ботов (honeypot), серверная валидация,
экранирование вывода.

## Адаптивность

Проверено на ширинах 360 / 414 / 768 / 1024 / 1440 px.

- до 1024 px — выезжающее меню-панель, закрывается по Esc, клику вне и по ссылке;
- сетки проектов и преимуществ перестраиваются 1 → 2 → 3 колонки;
- размеры шрифтов на `clamp()` — плавно тянутся без брейкпоинтов;
- поля формы 16 px, чтобы iOS не увеличивал масштаб при фокусе;
- уважается `prefers-reduced-motion`, есть видимый фокус и ссылка «к содержанию».

## Что стоит доделать перед публикацией

- заменить демо-тексты и проекты на реальные;
- добавить `robots.txt` и `sitemap.xml`;
- подключить HTTPS-редирект в `.htaccess`;
- закрыть папку `storage/` от прямого доступа (частично уже сделано правилом `FilesMatch`).
